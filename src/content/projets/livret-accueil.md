**Informer aujourd'hui pour bien démarrer demain !**

Une nouvelle école, c'est de nouveaux repères et plein de découvertes. Pour accompagner les familles, des équipes API rédigent un **livret d'accueil** :

- une **visite en images** de l'école : cours de récréation, espaces de jeu, marquages au sol… ;
- le **fonctionnement** de l'école au quotidien et son équipe ;
- les **projets** et les **informations pratiques** pour l'année.

## Les établissements qui le proposent

- Collège Jean Cocteau
- École élémentaire Le Prieuré
- École maternelle Bois-Bonnet
- École élémentaire François Mansart

Votre école n'a pas encore de livret ? Rejoignez l'équipe API de votre établissement pour le créer ensemble !
